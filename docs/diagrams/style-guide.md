# DevFlow Kit diagram style

Project-specific editorial style, applied with Diagram Design 2.6.

| Role | Token |
|---|---|
| Paper | `#faf9f6` |
| Ink | `#202936` |
| Muted text / connectors | `#58616b` |
| Accent | `#3659a8` |
| Accent tint | `#edf0f7` |
| Rules | `#d9d9d4` |
| Node fill | `#ffffff` |
| Optional / external fill | `#f1f1ee` / `#f0f0ed` |

Title: Instrument Serif, 40 px. Node names: Geist, 16 px, weight 600. Technical sublabels: Geist Mono, 12 px. Eyebrows: Geist Mono, 8 px. Editorial annotations: Instrument Serif italic, 14 px. Typography follows the upstream slide preset, not body text sizing for a website.

Canvas: 1280 × 720. Grid: 4 px. Node radius: 6 px. Connector stroke: 1.2 px. Rounded orthogonal elbow radius: 8 px. No shadows or gradients. Accent is reserved for one focal concept per figure. Files in `docs/assets` are generated; edit `scripts/draw_readme_diagrams.py` to make repeatable changes.
